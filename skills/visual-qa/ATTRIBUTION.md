# Source and port changes

Source: omo 5.1.19 installed plugin `skills/visual-qa` from code-yeongyu/oh-my-openagent. The checklist, dual-review methodology, CJK criteria, freshness/hygiene, pagination and reference-fidelity gates are retained. The self-contained bundled `scripts/visual-qa.mjs` uses Node standard modules only and is retained unchanged. Unneeded TypeScript development copies and repository AGENTS instructions are omitted. OMP changes replace Senpi/OpenCode dispatch fields with context/tasks and strict local JSON schemas, replace omowright with captures through the exposed browser or cua-driver tools, and replace the missing repository web-terminal script with real rendered terminal capture rather than text-only proof.
