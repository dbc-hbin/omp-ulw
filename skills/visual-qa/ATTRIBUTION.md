# Source and port changes

Source basis: upstream visual QA workflow. The checklist, dual-review methodology, CJK criteria, freshness/hygiene, pagination and reference-fidelity gates are retained. The self-contained bundled `scripts/visual-qa.mjs` uses Node standard modules only and is retained unchanged. Unneeded TypeScript development copies and repository AGENTS instructions are omitted. OMP changes replace legacy dispatch fields with context/tasks and strict local JSON schemas, replace the legacy browser bridge with captures through the native Eval `browser` or `computer` helpers, and replace the missing repository web-terminal script with real rendered terminal capture rather than text-only proof.

Browser integration re-port: [OMO revision 42d5746e72bfcfb782db6b5182b70a3e9c55f1cc](https://github.com/code-yeongyu/oh-my-openagent/tree/42d5746e72bfcfb782db6b5182b70a3e9c55f1cc/packages/shared-skills/skills/visual-qa). The upstream browser-setup capture matrix, mobile/DPR/media controls, top/end and motion capture, authenticated-session ownership, evidence hygiene and cleanup are mapped to OMP's native Eval `browser` prelude and raw Puppeteer `page` within `tab.run`. Console/network/HAR and frames link to the native browser references. The existing applicable-matrix scope and reviewer authority remain unchanged. OmOWright loaders/runtime bundles, BrowserSkill onboarding/daemon/extension installation and CloakBrowser runtime/fingerprint setup are not imported; native capability gaps remain explicit. Managed Chromium is project-shared, while authenticated criteria need an authorized real-session relay/CDP route. Relay remains optional.
