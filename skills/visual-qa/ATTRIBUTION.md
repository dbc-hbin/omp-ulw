# Source and port changes

Source basis: upstream visual QA workflow. The checklist, dual-review methodology, CJK criteria, freshness/hygiene, pagination and reference-fidelity gates are retained. The self-contained bundled `scripts/visual-qa.mjs` uses Node standard modules only and is retained unchanged. Unneeded TypeScript development copies and repository AGENTS instructions are omitted. OMP changes replace legacy dispatch fields with context/tasks and strict local JSON schemas, replace the legacy browser bridge with captures through the exposed browser or cua-driver tools, and replace the missing repository web-terminal script with real rendered terminal capture rather than text-only proof.
