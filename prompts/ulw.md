ulw

$ARGUMENTS

Use the ULW policy installed by the OMP extension. Start the input with `/ulw`, `ulw` or `ultrawork` to activate it; discussion or aliases later in a sentence do not activate it. The selected model profile supplies working methods within OMP's tool, permission and native mode contracts. Resume the existing native goal or selected workflow on follow-ups, preserving paused state until the user directs a resume. Bare ULW does not activate a specialised workflow or create a separate notepad or ledger.
